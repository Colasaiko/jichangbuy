# JichangBuy 独立品牌购买选购馆

为 **[Colasaiko/Home](https://github.com/Colasaiko/Home)** 仓库配套打造的机场品牌购买中心与独立落地页矩阵。

## 🌟 核心特性

- **品牌独立分开放**：拒绝单页臃肿堆叠，全网 35 个主流机场品牌均拥有**独立专属购买落地页**（Landing Page）。
- **购买转化向导**：
  - 醒目官方直达注册与购买按钮（CTA）。
  - **优惠码一键复制**：点击优惠券自动复制到系统剪贴板，并提供优雅的 Toast 弹窗提示。
  - **核心网络规格仪表盘**：线路架构（全 IPLC/IEPL/BGP）、协议支持、在线设备限制、速率限制、流媒体与 AI 解锁支持。
  - **全周期套餐价格表**：详细比对月付、季付、年付与一次性流量包原价与券后折后价。
  - **底端常驻吸底悬浮条**：带呼吸脉冲动效，手机和桌面端随时一键下单。
- **选购中心（首页）**：
  - 支持即时搜索（按品牌名、英文名、协议、线路模糊匹配）。
  - 多维度分类筛选 Tab（全 IPLC、IEPL、BGP 中转、有优惠券、高性价比 ≤¥20、不限时流量包）。
  - 每张卡片均提供【🚀 立即购买 / 注册 ↗】与【📄 独立购买落地页 →】双入口。
- **文件全量整理**：
  - `BRAND-INDEX.md`：35 个品牌的全景购买决策矩阵，包括线路、协议、月付/年付价格、独家优惠券、核心卖点、购买链接与避坑指南。

## 🚀 开启本地网站

无需复杂的环境安装，您现在可以通过以下任意一种方式一键开启本地网站：

### 方式一：使用 npm 运行（推荐）

```powershell
npm run dev
# 或
npm start
```
> 执行后会自动启动本地 HTTP 服务（默认端口 3000），并在您的默认浏览器中自动打开网站首页！

### 方式二：双击启动

直接双击根目录下的 **`start.bat`** 即可自动运行并打开网站。

### 方式三：重新生成页面（当修改品牌 markdown 后）

```powershell
npm run build
# 等同于运行 python scripts/build_site.py
```

## 📂 目录结构

- `package.json`：npm 脚本与项目配置。
- `server.js`：零外部依赖的 Node.js 本地开发静态服务器。
- `start.bat`：Windows 双击一键启动脚本。
- `brands/`：35 个品牌的 Markdown 原文件，含完整 YAML 元数据与评测介绍。
- `BRAND-INDEX.md`：品牌核心购买决策总表与场景推荐。
- `website/dist/`：生成的静态站点，包含：
  - `index.html`：购买选购中心（筛选与搜索）。
  - `style.css`：暗黑极客科技风高转化样式。
  - `brands/<slug>/index.html`：各品牌独立购买落地页。
- `scripts/build_site.py`：自动化站点构建脚本。
